# Prompt-Driven UI (提示词驱动的 UI)

阅读其他语言版本: [English](README.md) | [Tiếng Việt](README.vi.md) | [简体中文](README.zh-CN.md)

这是一个包含 100 多种网页设计（概念和变体）的展示库，所有设计完全由文本提示词（prompts）生成。探索 AI 驱动 UI 生成的无限可能，看看自然语言是如何转化为现代网页设计的。

## 🚀 项目概述

该项目的目标是展示大语言模型（LLM）和生成式 AI 从文本指令直接创建结构化、美观且功能齐全的 Web 界面的能力。通过提供特定的提示词，我们可以快速对各种 UI 布局、组件和样式进行原型设计和迭代。

## 📁 项目结构

- `index.html`: 用于浏览和探索所有生成设计的主画廊页面。
- `prompts/` & `prompts-en/`: 用于生成对应 Web 界面的自然语言文本提示词。
- `websites/` & `websites-en/`: 基于提示词生成的实际 UI 源代码（HTML、CSS、JS）。
- `thumbs/`: 生成网站的缩略图，用于画廊预览。
- `scripts/`: 用于构建或管理代码仓库的实用脚本。

## ✨ 主要特性

- **100+ AI 生成设计:** 丰富多样的 Web 界面概念集合。
- **提示词与代码映射:** 轻松对比输入的自然语言提示词与生成的输出代码。
- **多语言提示词:** 提示词和生成内容分为英语和其他语言环境。
- **完全开源:** 随意探索代码，修改提示词，并尝试生成你自己的设计。

## 🛠️ 如何使用

要查看展示，你不需要任何复杂的设置：

1. 将代码仓库克隆到本地机器。
2. 直接在 Web 浏览器中打开 `index.html` 文件。
3. 或者，为了获得最佳体验，请运行本地开发服务器：
   ```bash
   npx http-server
   # 或者
   python3 -m http.server
   ```
