How to Use the Prompts

A short guide on using AI to generate new website designs based on our 100 existing examples.

1 Generate the Exact Website

You can copy the provided markdown prompts and paste them into AI code generators (like Claude, ChatGPT, v0 by Vercel, or GitHub Copilot) to generate fully functional HTML/CSS/JS without any modifications.

2 a) Create a Similar Website

To create a unique website based on these examples, simply modify the variables in the prompt text:

  • Content: Swap out titles, descriptions, and placeholder text with your own.
  • Color Scheme: Update the color names (e.g., change "dark mode with neon accents" to "light mode with earth tones").
  • Layout Structure: Adjust layout instructions (e.g., "3-column grid" to "single column list").

3 b) Create a Multi-Language Website

Our prompts are available in both English and Vietnamese. To adapt a site for multiple languages or a completely new language:

  • Provide the layout and technical instructions in English to the AI for the best structural results.
  • Provide the localized copy (e.g., Japanese, Spanish) within the content section of the prompt.
  • Instruct the AI to add a "Language Switcher" toggle in the navigation bar.
