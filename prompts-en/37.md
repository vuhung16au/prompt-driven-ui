## Typography

IBM Plex Sans 400/500/600 for text; IBM Plex Mono 400/500 for data. H1 desktop 60 px/1.1 and mobile 36 px/1.2; H2 28 px; body 16 px/1.55; tables 14–16 px depending on density and readability inspection; labels 12–14 px only for short metadata. Currency values use tabular-nums.

## Grid, rhythm, and responsiveness

Desktop 12 columns, document 5 and data 7, max-width 1360 px, gutter 32 px, gap 24 px. From 768 px down, use Document/Data tabs when two panels are not wide enough; do not scale screenshots. Log/JSON has its own overflow container with labels and a copy button.

## Surfaces and materials

Radius 6 px, border 1 px, shadow 0 8 px 24 px rgba(0,0,0,.18) only on raised panels; no glassmorphism. Selection areas have an accent border with .08 fill opacity. Background grid pattern, if present, at .03 opacity, never overlaid on tables.

## Components and states

### Data rows

Field name, value, status, and edit controls. Text labels for 'Needs Review' / 'Confirmed'; do not rely on standalone colored dots. Clicking a row versus clicking an edit button must have distinct behaviors.

### Document area

Includes highlights based on normalized 0..1 coordinates of the image. Does not drift away from the target area upon resize; alt/description provides content for those who cannot see the image.

### Edit inputs

Inline editing with Save/Cancel; canceling reverts to the old value. Field-level validation, preventing total amounts from becoming NaN.

### Export outputs

Display real JSON/CSV generated from the current state. Copy action provides success/failure feedback; CSV properly escapes commas/quotes/newlines, without using the Excel name for CSV data.

## Motion and reduced motion options

Area highlight 180 ms and row state 200 ms; when motion is disabled, associations remain visible via field codes. No fake OCR processing delays, no scrolling background code rain.

## Things to avoid

Prohibited: fabricated confidence scores, real customer data, fake processed uploads, cyberpunk glitches, coin/orbital graphics, decorative KPI dashboards, or claiming static mapping is live AI inference.

## Value verification before deployment

Measure contrast of text/surface pairs and actual states; do not rely on isolated hex colors to claim compliance. Check for complete Vietnamese diacritics and font fallbacks.
