3. Aurora specification
Aurora: dark background, soft blue and teal glowing halos behind; if the brand has its own color palette, shift halos to the corresponding colors. A clear headline, explanatory sentence, and primary action prominent over a low-noise background area. Additional sections only answer what users need before taking action, without cramming rows of feature cards. Gradient serves as ambient background atmosphere, not a layer that obscures text. Maintain links to essential information and return paths if the flow requires. Narrow screens compress halos, buttons are easy to tap; static background remains beautiful when motion is disabled.
Detail to maintain: This is the most clichéd style. Before delivery, check whether the page looks like every other AI page, then change the color pair and layout to differentiate it.
Note when applying: Very easy to become clichéd. If gradient is purple-to-blue, the page will look identical to thousands of other pages — switch to a color pair derived from your brand.

Variant: Aurora Light / light field supporting note-taking tools. Proposed specifically for this template, not claiming to be the sole standard of the style.

## Typography

Manrope 600/700 for headings, Inter 400/500 for body. H1 desktop 72 px/1.08, tablet 52 px, mobile 38 px/1.18; H2 32 px; body 18 px/1.65; UI 16 px; metadata 14 px. Only one headline word may have a gradient if sufficient contrast is maintained; body is always solid.

## Grid, rhythm, and responsive

Max-width 1200 px, centered hero but the tool section has two 6/6 zones balanced by content volume; padding 32 px. Mobile single column following input→output, gutter 20 px; provide jump links between the two zones instead of a sticky summary obscuring content.

## Surfaces and materials

Three large radial gradients at 120–160% of frame, different offset centers, background blur 48–80 px if performance budget permits; prefer static CSS radials over heavy images. White panel .94 opacity, radius 18 px, border 1 px, shadow 0 12 px 32 px rgba(48,41,87,.06). Do not turn the entire panel into glass.

## Components and states

### Context selection

Segmented controls with full names; selected fill accent and white text, distinct focus. Three datasets labeled with sample notes.

### Source notes

Each row has an id, content, and highlight option. Do not let users edit text and then return old output as if understood by AI.

### Results

Three groups: decisions / action items / open questions; each item has a specific source link. Empty groups display "Not in notes" instead of fabricating content.

### Copy

Copy markdown from currently selected result; if clipboard API is blocked, open a readonly textarea for manual copying. Do not show success toast when Promise is rejected.

## Motion and reduced-motion plan

Three light zones drift very slowly at 20 s, transform amplitude 12 px. Includes pause, mobile uses static if jank is detected. Results fade 250 ms, no fake loading. Reduced-motion disables the light field and fade.

## Things to avoid

Prohibited: gradient-only without product, direct AI badge on mock data, multi-layer nested glass, body gradient, storing credentials or automatically sending notes externally.

## Value checks before deployment

Measure contrast of text/surface pairs and actual states; do not rely on isolated hex colors to declare compliance. Check full Vietnamese diacritics and fallback fonts. The content layout, datasets, cover, and distinct scenarios are located right after this brief in the standalone prompt.
