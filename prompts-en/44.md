# Design Style: Trustworthy Dark Fintech

## 1. Design Philosophy

**Core Principle**: Security meets modern simplicity. This design language is built for applications that require user trust (like finance, crypto, or secure data management). It uses a deep, solid background to convey stability and a vibrant, high-contrast accent color to guide the user's eye to successful actions and conversions.

**The Vibe**: Premium, secure, frictionless, and contemporary. It feels like a high-end mobile app translated to the web. There is no visual clutter—every element has a purpose, communicating efficiency and reliability.

**Visual Signatures**:

* **Deep Slate Canvas**: Moving away from pure black or dark gray, the base `#192625` adds a subtle organic/forest undertone that feels more premium and less harsh.
* **Electric Trust Accents**: Vibrant lime/yellow-green is used for primary actions, success states, and checkmarks, creating an immediate visual reward.
* **Crisp Typography**: Strict geometric sans-serif fonts with very specific, dialed-in line heights (e.g., 105% to 115%) for a tightly engineered look.
* **Subtle Elevation**: Depth is achieved not through heavy drop shadows, but through subtle surface lightening and delicate 1px borders (`border-white/10`).

## 2. Design Token System (The DNA)

### Color Palette

**Base Colors**:

```
Background:    #192625    (Deep slate/forest green - the foundation)
Surface:       #233130    (Slightly lighter slate for cards/containers)
Foreground:    #FFFFFF    (Pure white - for headings and primary text)
Muted:         #A0AAB2    (Light cool gray - for secondary text/captions)
Border Base:   rgba(255, 255, 255, 0.1) (Subtle dividers)

```

**Accent Colors**:

```
Primary:       #B3F05D    (Electric Lime / Neon Green - for CTAs and success)
Primary Hover: #C4F575    (Lighter lime for interactions)
Secondary:     #FFFFFF    (White - used as a secondary button/accent)

```

### Typography System

**Font Stack**:

* **Primary**: `"Inter", "SF Pro Display", sans-serif` — Engineered, neutral, highly legible.

**Type Scale & Styling (Based on Figma specs)**:

* H1: `text-[42px] leading-[1.05] font-bold tracking-tight`
* H2: `text-[32px] leading-[1.09] font-bold tracking-tight`
* H3: `text-[20px] leading-[1.09] font-semibold`
* Body: `text-[16px] leading-[1.09] font-normal`
* Caption: `text-[10px] leading-[1.05] font-medium tracking-wide uppercase`
* Link: `text-[12px] leading-[1.15] font-medium text-accent`

### Radius & Border

```
radius.sm:       8px        (Small tags, internal inputs)
radius.base:     12px       (Standard cards, dropdowns)
radius.full:     9999px     (Primary buttons, pill-shaped tags)

```

* **Borders**: Use `border border-white/10` to define cards against the dark background. Do not use colored borders unless indicating a specific focus state.

## 3. Component Stylings

### Buttons

**Primary CTA**:

* Background: `bg-[#B3F05D]`
* Text: `text-[#192625] font-bold` (Dark text on bright background for contrast)
* Radius: `rounded-full` (Pill shape)
* Padding: `px-8 py-3` to `px-10 py-4`
* Hover: `hover:bg-[#C4F575] hover:scale-[1.02]`
* Transition: `transition-all duration-200`

**Secondary/Outline Button**:

* Background: `bg-transparent`
* Border: `border border-white/20`
* Text: `text-white font-medium`
* Hover: `hover:bg-white/5`

### Cards & Containers

* Background: `bg-[#233130]` or `bg-white/[0.03]`
* Border: `border border-white/10`
* Radius: `rounded-2xl`
* Padding: Generous internal spacing (`p-6` to `p-10`).
* Shadow: Flat design preferred, but can use very subtle ambient shadow `shadow-[0_8px_30px_rgb(0,0,0,0.12)]`.

### Trust Signals (Lists/Features)

* Use standard unordered lists but replace standard bullets with custom SVG checkmarks in the `#B3F05D` accent color.
* Align items vertically with `gap-4`.

## 4. Layout Strategy

* **Hero Section**: 50/50 split on desktop. Bold H1 and CTAs on the left, high-fidelity app mockup or dashboard preview on the right.
* **Section Spacing**: `py-20` to `py-24` to allow the dark theme to breathe.
* **Max-Width**: `max-w-7xl` for main content.

## 7. Motion and Feedback

Keep motion highly functional. A simple fade-in or slide-up on scroll is acceptable, but avoid bouncy, playful animations. The aesthetic is serious and secure. Reduced-motion must retain all information and content order.
