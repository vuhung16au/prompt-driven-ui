# Hazelnut - Playful Geometric Website

This is a prototype landing page for the Hazelnut craft project, designed in the Playful Geometric style.

## Features
- Dynamic age filter.
- Interactive activity selection and summary.
- Responsive layout.
- Empty state and reset button.
- Safe design, no collection of sensitive child data.

## Structure
- `index.html`: Main interface.
- `style.css`: Color variables, layout, spacing, and effects (with reduced-motion fallback).
- `script.js`: Handles filtering, activity selection, and static interactions.

## Usage
Simply open the `index.html` file in any web browser. No server setup is required.
