# An Nguyen Portfolio (Prompt 09)

Static website design project based on the Portfolio / Luxury Editorial style.

## Technologies Used
- HTML5, CSS3, JavaScript.
- Tailwind CSS (via CDN) for rapid Layout, Typography, and Color management.
- Google Fonts (Inter, Playfair Display).

## Key Features
- Large, high-contrast typography pairing Serif and Sans-serif fonts.
- Grayscale images by default, transitioning to full color on hover (1500ms duration).
- Visible vertical grid lines creating an editorial structure.
- Generous negative space.
- Basic interactive form (email validation) that does not submit real data (Demo).

## Directory Structure
- `index.html`: Main interface.
- `style.css`: Custom CSS extensions beyond Tailwind.
- `script.js`: Form validation logic.

## How to Run
Open `index.html` directly in a browser or use Live Server.
