# DesignSpace - From brief to approved version

A website simulating a workspace for reviewing design versions, collecting feedback, and handing over projects.
Designed based on the Modern Dark style (Linear / Vercel style).

## Features
- **Tab Switching**: Smoothly switch between Brief, Mockup, Feedback, and Handover.
- **Version Comparison**: Visually compare the differences between v1.0 and v2.0.
- **Feedback Handling**: Mark feedback as resolved, automatically updating progress.
- **Spotlight & Parallax Effects**: Subtle animations, mouse-tracking interactivity (disabled when reduced-motion is enabled).

## Technologies
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Fonts: Inter & JetBrains Mono

## How to run
Simply open the `index.html` file in any modern web browser. No server environment setup is required.
