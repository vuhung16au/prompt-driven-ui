# Say It Right - Bold Typography (English Version)

A website built using the Bold Typography style for a project focusing on copywriting and brand messaging.

## Key Features:

1. **Typographic Poster:** A large hero section with a clear message: "SAY IT RIGHT. REMEMBER IT LONG."
2. **Three Case Studies:** A grid presenting 3 concise case studies.
3. **Before & After:** A toggle to compare vague old messaging with clearer new messaging.
4. **How to Find the Right Words:** A 3-step process with large numbered typographic elements.
5. **Brief Tester:** A small form to input a brand name and goal, formatting it into a brief.

## Design:
- Color Palette: Black Background (`#0A0A0A`), White Text (`#FAFAFA`), Vermillion Accent (`#FF3D00`).
- Typography: Uses Inter Tight, Inter, and Fira Code (mono) with strict typographic hierarchy following Bold Typography standards.

Open `index.html` in a web browser to view the result.
