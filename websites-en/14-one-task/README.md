# 14 One Task Focus - Minimal Dark
A focus timer (Pomodoro) application designed in the Minimal Dark style.

## Features
- Choose a task and set a duration (15, 25, 45 minutes, or custom).
- Minimalist interface focused purely on the current task.
- Saves demo sessions history locally (localStorage).
- Fully supports keyboard navigation and `prefers-reduced-motion` for a consistent cross-device experience.
