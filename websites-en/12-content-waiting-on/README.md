# Nhịp Work - Approval Management Demo

This project demonstrates the Approval Management interface designed using the Corporate Trust (Enterprise) style.

## Technologies Used
- HTML5, CSS3, JavaScript ES6
- Tailwind CSS (via CDN)
- Plus Jakarta Sans font
- Lucide Icons (via CDN)

## How to run
Simply open `index.html` in your browser to view the interface and test out the interactions.

## Features
- View a list of requests pending approval.
- Filter by status and search.
- Request details pane to "Approve" or "Request Revisions".
- Interaction history log.
- Responsive design for mobile support.
