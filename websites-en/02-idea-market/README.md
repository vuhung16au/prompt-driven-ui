# Idea Market

A UI design project following the **Maximalism** style, adhering to the design principles set out in the requirements.

## Features
- Broken grid layout with asymmetrical components.
- Bold use of color (5 accent colors), massive text with layered shadows, and mixed borders.
- **Explore Booths** feature with non-refreshing filters.
- **Event Schedule** feature allowing saving up to 4 events, detecting time conflicts, and displaying alerts (does not clear saved schedule when changing filters).

## File Structure
- `index.html`: Semantic HTML structure with clearly defined functional areas.
- `style.css`: CSS variables, shadow effects, colors, typography, and animations.
- `script.js`: Logic for filtering events, saving schedules, and resolving conflicts.

## How to run
Open `index.html` in a web browser. No server is required since the data is mocked in `script.js`.
