Understand the model?

You can reset to the initial data to start over, or learn about the terminology alongside.

Data packet containing transaction, action, or record information. Each block has a unique identifier generated from its own content.
A subsequent block always stores the hash of the previous one. This creates an unbreakable sequence that cannot be tampered with or intercepted.
The act of recalculating block hashes. If a block's content changes, its hash changes accordingly, breaking the link with the next block.
