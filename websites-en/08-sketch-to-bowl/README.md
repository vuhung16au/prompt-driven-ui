# 08-sketch-to-bowl (English Version)

A pottery workshop website designed with the Hand-Drawn / Sketch style.

## Design Features
- **Style**: Hand-drawn Sketch (paper background, wobbly borders, handwritten text, playful rotation).
- **Colors**: Warm Paper #fdfbf7, Pencil Black #2d2d2d, Correction Red #ff4d4d, Ballpoint Blue #2d5da1.
- **Typography**: Kalam (Heading) and Patrick Hand (Body) from Google Fonts.
- **Functionality**:
  - Interactive shape selection using JavaScript.
  - Form drafts are saved into `sessionStorage`.
  - Accessible focus states and "pressing flat" active states for buttons.
- **Responsive Strategy**: Mobile-first layout collapsing grids to single columns. Disabled rotational tilt on small screens for better readability.

## Instructions
Open `index.html` in your browser. No server or framework is required.

*Data used is placeholder content, form backend integration is mocked.*
