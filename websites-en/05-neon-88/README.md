# NEON 88

Project 05 implemented in Vaporwave / Outrun style for the English prompt.

## Features
- Infinite perspective grid using CSS
- Interactive 3-milestone timeline
- Pseudo-terminal UI designs
- Skewed buttons and neon glowing hover states
- Fully responsive design
- Accessibility: Focus management, semantic HTML, reduced-motion support.

## Usage
Open `index.html` in your browser.
