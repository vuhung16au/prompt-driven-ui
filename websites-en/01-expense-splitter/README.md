# 01 - Expense Splitter

This project is a website for calculating and sharing expenses for a group, designed in the Claymorphism style.

## Features
- Add up to 6 members.
- Add expenses (expense name, amount, payer).
- Automatically split costs equally (including 1 VND remainders).
- Easily copy the summary to share with friends.

## Technologies Used
- HTML5, CSS3, JavaScript (Vanilla).
- Fonts: Nunito and DM Sans from Google Fonts.
- Design style: High-Fidelity Claymorphism (multi-layer shadows, convex/concave effects, blob backgrounds).

## File Structure
- `index.html`: Page structure
- `style.css`: UI styling, shadows, colors.
- `script.js`: Calculation logic and state management.
