# "Words Have Rhythm Too" Project

## Goal
The project applies the Kinetic Typography design style, placing typographic art and motion at the center of the visual experience.

## Features
- Infinite scrolling marquees, massive viewport text.
- Buttons to toggle motion effects individually or globally.
- Interactive form for "Motion Brief" testing.
- Strong accessibility support (focus outlines, prefers-reduced-motion, etc.).

## Technologies
- HTML5, CSS3.
- Vanilla JavaScript.

## How to run
Open `index.html` in a web browser.
