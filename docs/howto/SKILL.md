# How to Use the Website Designer Skill

This guide explains how to install and use the Website Designer skill to generate new website designs.

## Setup
1. Ensure the `docs/agents/SKILL.md` file is loaded into your agent's available skills context.
2. Provide your agent with access to your existing website designs so it can use them as reference templates.

## Usage
You can interact with the agent using natural language prompts. The skill is designed to interpret your intent and generate appropriate layouts, content, and styling.

### Sample Prompts

To create a brand new website from scratch, use:
> "Create a website"

To create a website by remixing a structure from an existing reference, use:
> "Based on existing website design, create a new ticket booking website"

## Best Practices
* **Be Specific:** If you have preferred colors, fonts, or sections (e.g., Hero, Testimonials, Footer), mention them in your prompt.
* **Provide References:** Point the agent to a specific URL or existing template in your workspace to get better, more structurally sound results.
