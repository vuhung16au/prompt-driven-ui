# Website Designer Skill

This skill is designed to help users rapidly prototype, plan, and create new website designs.

## Usage Guide
When a user asks to generate a website design, follow these guidelines:
1. **Analyze Request:** Identify the core purpose of the website (e.g., ticket booking, portfolio, e-commerce).
2. **Review Existing Designs:** If the user asks to base the new site on an "existing website design", locate any existing layouts or prompts provided by the user in their workspace to use as a structural foundation.
3. **Generate Design:** Provide a complete design structure (HTML/CSS, layout instructions, or UI component lists) tailored to the new topic.

## Sample Prompts to Trigger this Skill
* `Create a website`
* `Based on existing website design, create a new ticket booking website`
