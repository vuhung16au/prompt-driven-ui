# Say It Right - Bold Typography (Bản tiếng Việt)

Website được xây dựng theo phong cách Bold Typography cho một dự án tập trung vào câu chữ và thông điệp truyền thông.

## Các tính năng chính:

1. **Poster bằng chữ:** Header lớn với thông điệp rõ ràng "NÓI ĐÚNG. NHỚ LÂU."
2. **Ba bài toán:** Trình bày 3 case study ví dụ ngắn gọn, có cấu trúc lưới.
3. **Trước và sau:** Nút Toggle để so sánh câu chữ cũ (còn mơ hồ) và câu chữ mới (rõ ràng hơn).
4. **Cách tìm câu đúng:** Trình bày 3 bước thực hiện với con số to rõ.
5. **Thử Brief:** Một form nhỏ nhận tên thương hiệu và mục đích để xem lại dưới dạng brief tóm tắt.

## Thiết kế:
- Tone màu: Nền đen (`#0A0A0A`), Chữ trắng (`#FAFAFA`), Điểm nhấn Cam (`#FF3D00`).
- Typography: Sử dụng font Inter, Fira Code (mono) và kích thước chữ phân cấp rõ ràng theo chuẩn thiết kế Bold Typography.

Mở file `index.html` bằng trình duyệt để xem kết quả.
