# Portfolio An Nguyễn (Mẫu 09)

Dự án thiết kế website tĩnh theo phong cách Portfolio / Luxury Editorial.

## Công nghệ sử dụng
- HTML5, CSS3, JavaScript.
- Tailwind CSS (qua CDN) để quản lý Layout, Typography và Màu sắc nhanh chóng.
- Google Fonts (Inter, Playfair Display).

## Đặc điểm nổi bật
- Typography lớn, có độ tương phản cao, dùng kết hợp Serif và Sans-serif.
- Ảnh đen trắng mặc định, chuyển màu khi hover (duration 1500ms).
- Grid lines dọc hiển thị mờ tạo cấu trúc Editorial.
- Các khoảng trống lớn (generous negative space).
- Forms tương tác cơ bản (kiểm tra email) không gửi dữ liệu thật (Demo).

## Cấu trúc thư mục
- `index.html`: Giao diện chính.
- `style.css`: Các tùy chỉnh CSS mở rộng ngoài Tailwind.
- `script.js`: Logic validation form.

## Hướng dẫn chạy
Mở file `index.html` trực tiếp trên trình duyệt hoặc sử dụng Live Server.
