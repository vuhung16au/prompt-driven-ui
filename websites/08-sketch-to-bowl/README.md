# 08-sketch-to-bowl

Website giới thiệu xưởng làm gốm theo phong cách Sketch (phác thảo tay).

## Đặc điểm thiết kế
- **Phong cách**: Sketch (nền giấy, viền không đều wobbly, chữ viết tay, nghiêng nhẹ).
- **Màu sắc**: Giấy #fdfbf7, Chì #2d2d2d, Đỏ #ff4d4d, Xanh #2d5da1.
- **Font chữ**: Kalam (Heading) và Patrick Hand (Body) - Hỗ trợ tốt tiếng Việt.
- **Tính năng**: 
  - Chọn dáng gốm thay đổi nội dung (JavaScript).
  - Form ghi nháp ý tưởng lưu vào `sessionStorage`.
  - Phản hồi bàn phím (focus) và hiệu ứng hover dạng nét đè shadow.
- **Responsive**: Mobile-first, chuyển đổi mượt sang tablet và desktop. Tắt hiệu ứng nghiêng trên mobile để đảm bảo nội dung dễ đọc.

## Hướng dẫn chạy
Mở file `index.html` trực tiếp trên trình duyệt. Không cần cài đặt server hay framework.

*Dữ liệu đang dùng là nội dung mô phỏng, phần kết nối backend (form) chưa được thực thi thật.*
