# 14 One Task Focus - Minimal Dark
Ứng dụng đếm ngược thời gian tập trung (Pomodoro) theo phong cách Minimal Dark.

## Tính năng
- Chọn việc cần làm và thiết lập thời lượng (15, 25, 45 phút hoặc tuỳ chỉnh).
- Giao diện tối giản, tập trung vào công việc đang thực hiện.
- Hỗ trợ lưu trữ phiên làm việc trong bộ nhớ tạm (localStorage).
- Hỗ trợ đầy đủ phím tắt và `prefers-reduced-motion` cho trải nghiệm di động/máy tính bàn nhất quán.
