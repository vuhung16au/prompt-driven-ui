# DesignSpace - Từ brief đến bản được duyệt

Website mô phỏng một không gian làm việc (workspace) dành cho việc thiết kế, nhận phản hồi và bàn giao dự án. 
Được thiết kế dựa trên phong cách Modern Dark (Linear / Vercel style).

## Tính năng
- **Tab Chuyển đổi**: Chuyển đổi giữa Brief, Bản dựng, Phản hồi, và Bàn giao mượt mà.
- **So sánh Phiên bản**: Xem trực quan sự khác biệt giữa v1.0 và v2.0.
- **Xử lý Phản hồi**: Đánh dấu hoàn tất phản hồi, tự động cập nhật tiến độ.
- **Hiệu ứng Spotlight & Parallax**: Chuyển động nhẹ nhàng, tương tác theo trỏ chuột (tắt khi bật reduced-motion).

## Công nghệ
- HTML5
- Tailwind CSS (qua CDN)
- Vanilla JavaScript
- Font: Inter & JetBrains Mono

## Hướng dẫn chạy
Chỉ cần mở file `index.html` bằng bất kỳ trình duyệt web hiện đại nào. Không yêu cầu cài đặt môi trường server.
