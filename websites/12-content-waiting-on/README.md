# Nhịp Work - Minh hoạ giao diện Quản lý Phê duyệt

Dự án này là minh hoạ cho giao diện Quản lý Phê duyệt theo phong cách Enterprise (Corporate Trust).

## Công nghệ sử dụng
- HTML5, CSS3, JavaScript ES6
- Tailwind CSS (via CDN)
- Font chữ Plus Jakarta Sans
- Lucide Icons (via CDN)

## Cách chạy dự án
Chỉ cần mở file `index.html` bằng trình duyệt để xem giao diện và thử nghiệm tương tác.

## Tính năng
- Xem danh sách yêu cầu cần duyệt.
- Lọc theo trạng thái và tìm kiếm.
- Chi tiết yêu cầu và thực hiện "Duyệt" hoặc "Yêu cầu sửa".
- Ghi log lịch sử tương tác.
- Thiết kế responsive, hỗ trợ di động.
