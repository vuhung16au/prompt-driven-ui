# Hạt Dẻ - Playful Geometric Website

Đây là giao diện minh họa (landing page) cho dự án thủ công Hạt Dẻ, được thiết kế theo phong cách Playful Geometric.

## Tính năng
- Bộ lọc động theo độ tuổi.
- Tương tác chọn hoạt động và xem tổng kết.
- Giao diện responsive.
- Trạng thái trống (empty state) và nút thử lại (reset).
- Thiết kế an toàn, không thu thập dữ liệu nhạy cảm của trẻ.

## Cấu trúc
- `index.html`: Giao diện chính.
- `style.css`: Hệ thống biến màu, bố cục, khoảng cách và hiệu ứng (có fallback cho reduced-motion).
- `script.js`: Xử lý lọc, chọn hoạt động và tương tác tĩnh.

## Sử dụng
Chỉ cần mở file `index.html` trong trình duyệt web bất kỳ. Không cần cài đặt server.
